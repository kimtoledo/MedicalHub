# Dentra.ph SVG Logo Pack

- `dentra-logo-primary-stacked.svg` — stacked marketing/brand use
- `dentra-logo-icon.svg` — favicon/icon mark
- `dentra-logo-white.svg` — reversed logo for dark purple backgrounds
- `dentra-logo-monochrome.svg` — one-color printing/document use
- `dentra-pwa-app-icon.svg` — square PWA/app icon master

Brand colors:
