# Clinical Files and Media

> **Status:** 🔜 Future — MVP 2

---

## What & Why

Dentists need to attach radiographs, intraoral photos, consent forms, and lab referrals to patient encounters. Files must be stored privately — never publicly accessible without authorization.

---

## Done looks like

- Dentist/staff can upload files from within an encounter: radiographs, intraoral/extraoral photos, consent forms, referral letters, lab results.
- Each file is tagged with: patient, encounter, tooth/area (optional), file type, upload date, uploaded by.
- Files are stored in private cloud storage (Replit Object Storage or S3-compatible).
- Access is via short-lived signed URLs generated by the API on each request — never a direct public link.
- Upload validation: file type allowlist, max file size, malware scan if feasible.
- Files are tenant-scoped; cross-clinic access is rejected at the API.

---

## Out of scope

- Patient-accessible file downloads (MVP 3 patient portal).
- Video recordings.
